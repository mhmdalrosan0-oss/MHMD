# تحليل مشروع أستاذ خلدون (2026-9.aep)

الملف الأصلي (aep) لم يُحفظ هنا. الأدوات تقرأه من مسار مكتوب داخل `tools/aep.py` (متغير F)، عدّله قبل التشغيل.

- `report.html`: الصفحة التفاعلية (منشورة أيضاً: https://claude.ai/artifact/NXbju4mJ37QbNfkYbqWA9W)
- `data/comp0.txt`: كل لاير وكي فريم في الكومب الرئيسي مع Speed/Influence ومنحنى كل مقطع
- `data/data.json`, `data2.json`: البيانات المستخرجة
- `tools/`: محلّل RIFX كتبته من الصفر (aep.py, model.py, cos.py, report2.py)

## ملخص النتائج
- 2160×3840، 50fps، 29.22ث، 47 لاير، 302 كي فريم.
- كل مفاتيح Bezier بسرعة 0 وتأثير 70-100% (الأكثر 80%). الدخول: Linear ثم هبوط ناعم. الخروج: تسارع بتأثير 100%.
- الشخص مفصول بـ Keylight، ويعمل كالكاميرا: لاير الشخص أب للخلفية واللوور ثيرد والكتاب وكلمات «واضح ومحدد وسريع».
- النصوص بريسيتات AtomX/Zodo بماركرات IN/OUT، وتوهج Deep Glow أزرق #0955E1.
- القصّات في الفيديو الخام (5.68, 18.18, 20.32, 21.44, 22.68) تقع بجانب أحداث بصرية.
